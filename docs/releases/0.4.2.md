# oh-my-patent 0.4.2

Release preparation / 待发布。Package publication is tracked in
[GitHub Releases](https://github.com/illusionaireal/oh-my-patent/releases).

## 中文

本版本汇总已合并的 [#12](https://github.com/illusionaireal/oh-my-patent/pull/12)
和 [#13](https://github.com/illusionaireal/oh-my-patent/pull/13)，同步 CLI、插件和独立 Skill 的版本。

- 修复 npm/npx 安装后的哨兵入口和独立检查运行时，各宿主读取自己的 MCP 配置。
  哨兵分别报告基础运行环境、检索、草稿绘图和最终预览能力；配置存在不证明实际工具可用。
- 检索无来源时阻塞；仅有学术来源时须明确接受降级；专业来源通过配置检查后仍需宿主验证。
  检索能力缺口不阻塞基于已有证据的独立撰写或绘图。
- 绘图优先复用可执行的已保存本地方案，再采用本地偏好、SVG 或其他可用本地方案。
  缺少 Mermaid 仅警告。真实计时选择 30 秒未响应后采用当前本地默认；无计时能力立即默认。
  能力刷新和重复提示保留原期限，规格或宿主会话等上下文变化则需要重新规划。
- 保留未改动附图的有效审阅；正文、规格、图源、结果或执行方式变化仍使审阅失效。
  后端切换同步兼容输出格式，安装态新项目继承工作区配置，任务覆盖优先于项目和工作区配置。
- 宿主对本地渲染执行 60 秒期限。真实失败或超时记录校验通过后，可从本地渲染器转用一次可用 SVG。
  运行时校验记录，实际执行与取消由宿主负责；SVG 或远程失败不继续自动兜底。
- 中英文 README 和安装指南使用短命令 `npx skills add illusionaireal/oh-my-patent`。
  该命令跟随仓库默认分支；npm `@latest` 跟随已发布包。安装时选择 Project 和 Copy，
  或追加 `--skill oh-my-patent --copy` 显式指定复制。

### 升级

插件用户在版本发布后运行 `npx oh-my-patent@0.4.2 adapt install`；仅更新一个宿主时
追加 `--tool <host>`（`claude-code`、`codex` 或 `opencode`）。安装全局 CLI 后仍需更新工作区集成。
发布前可按[源码安装说明](../skill.md#plugin-mode-from-source)构建此版本。

Skill 用户通过原安装方式更新完整目录，保留 `SKILL.md`、`references/`、`assets/` 和 `scripts/`。
旧项目使用版本化绘图接口前，先检查迁移 dry-run 并由用户确认；迁移后使用共享运行时写入项目。

默认选择或失败兜底不授权远程披露或付费。没有预览能力可以画草稿；最终必需附图仍需
实际预览、当前有效审阅和人工验收。保留 14 个代理、6 项技能和 9 条命令。

## English

This version includes merged [#12](https://github.com/illusionaireal/oh-my-patent/pull/12)
and [#13](https://github.com/illusionaireal/oh-my-patent/pull/13), with matching CLI,
plugin and standalone Skill versions.

- Repair installed sentinel entry points and independent check runtimes, selecting each
  host's MCP configuration. Report runtime, research, draft drawing and final preview
  readiness separately. Configuration presence does not establish actual tool access.
- Block research without retrieval sources; require explicit acceptance of academic-only
  coverage. Professional-source configuration still needs host verification. Independent
  drafting or drawing from existing evidence can continue while retrieval is unavailable.
- Reuse an available saved local figure choice, then try the local preference, SVG or
  another available local renderer. Missing Mermaid is a warning. Timed hosts default
  after 30 seconds without a response; other hosts default immediately. Observation
  refresh and repeated prompts retain the deadline; changed context requires replanning.
- Retain valid reviews of unchanged figures while substantive content or execution changes
  invalidate review. Normalize formats when selecting a backend. Installed new projects
  inherit workspace configuration; task overrides take precedence over project and workspace.
- Hosts enforce a 60-second local-render deadline. Validated failure or timeout evidence
  permits one fallback from a local renderer to available SVG. The runtime validates records;
  the host executes and cancels tools. SVG and remote failures have no automatic fallback.
- Use `npx skills add illusionaireal/oh-my-patent` in installation entry points. It follows
  the repository default branch, while npm `@latest` follows published packages. Choose
  Project and Copy, or append `--skill oh-my-patent --copy` for explicit copy selection.

### Upgrade

After publication, plugin users run `npx oh-my-patent@0.4.2 adapt install` in the workspace.
Append `--tool <host>` for one host (`claude-code`, `codex` or `opencode`). Updating the
global CLI alone does not update workspace integrations. Before publication, use the
[source installation instructions](../skill.md#plugin-mode-from-source).

Skill users update the complete directory through their existing installation method,
keeping `SKILL.md`, `references/`, `assets/` and `scripts/` together. Before legacy projects
use versioned figure operations, inspect a migration dry-run and obtain user confirmation;
use the shared runtime for subsequent project writes.

Defaults and failure fallbacks do not authorize remote disclosure or spending. Drafts
can proceed without preview; final required figures still need actual preview, current
review and human acceptance. The 14 agents, 6 skills and 9 commands remain available.

## Verification / 验证

Run `npm run lint`, `npm test`, `npm run package:skill`, `npm run verify:artifacts`,
`npm run publish:skill -- --dry-run`, and `npm run publish:release -- plugin --dry-run`
and `npm run publish:release -- assets --dry-run` to reproduce local release checks.
See the [release ledger](../../specs/007-release-0.4.2/tasks.md) and the submitted PR's CI.

Real host drawing, timed UI, tool cancellation and remote providers require separate
acceptance. Synthetic tests and archive checks do not establish those capabilities.
真实宿主绘图、计时 UI、工具取消和远程服务仍需单独验收，合成测试与归档校验不能替代。
