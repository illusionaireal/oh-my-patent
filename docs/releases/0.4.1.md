# 0.4.1

- 修复插件哨兵的子代理注册及检查命令；安装时分发独立检查运行时，支持 npm/npx
  安装、中文与空格路径，以及安装目录迁移。
- 各宿主明确读取自己的 MCP 配置，避免混合安装时读取错误宿主的设置；配置检测
  与实际连接验证分别记录。
- Archimedes 在首次检索及恢复项目时执行检查，保存实际结果和能力缺口；独立 Skill
  激活时加载哨兵角色并执行随包的 doctor。
- 检索门禁改为分档：零源硬阻塞；仅 Google Scholar / Semantic Scholar 默认阻塞，
  需用户明确接受降级并留存确认依据和局限；至少配置一个专业专利源通过配置门禁。
  实际宿主检索可用性仍需另行观察，配置不等于连通；恢复时重新检查。
- 统一插件与 Skill 的逐图方案选择，优先可执行本地偏好/直接 SVG；mmdc 缺失改为
  启动警告。真实计时交互支持 30 秒超时默认，无计时能力立即默认，均记录系统来源。
  选择/能力/规格绑定后执行，最终必需附图仍需实际预览和当前审阅；默认不授权外发或付费。
- 保留插件的 14 个代理、6 项技能、9 条命令，以及独立 Skill 安装模式。

已有插件工作区需重新执行 `oh-my-patent adapt install`（或对应 npx 命令）以更新
生成配置和检查运行时。Skill 用户通过原安装方式更新完整 Skill 目录。

CI 覆盖代理配置、检查器执行、迁移及 npm 归档；实际模型宿主的委派调用需独立
验收记录，详见[验证台账](../../specs/005-sentinel-startup/tasks.md)。
