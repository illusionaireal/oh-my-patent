# oh-my-patent — Logo System

## Brand decision

**Primary:** blue Archimedes / Eureka mark.
**Secondary:** black monochrome version for one-color and print use.
**Dark theme:** the same primary mark placed on a deep navy field.

## Assets in this repository

- `png/logo-primary.png` — 1900×600 primary horizontal lockup (README / docs header).
- `png/mark-primary-512.png` — 512×512 primary mark (GitHub repository avatar, social preview).
- `png/favicon.ico` — multi-size favicon (16/32/64/128/256 px).
- `README-snippet.md` — the header snippet the top-level READMEs embed.

## Held outside the repository

The delivered brand bundle also contains heavy source artwork that is intentionally not versioned here, because each SVG embeds multi-megabyte raster data:

- `svg/mark-primary.svg`, `svg/logo-primary.svg` (≈2.8 MB each) — vector/CSS-friendly lockups.
- `svg/mark-monochrome.svg`, `svg/logo-on-dark.svg` — monochrome and dark-background lockups.
- `png/logo-on-dark.png`, `png/mark-on-blue-*.png`, `png/mark-on-dark-*.png`, `png/mark-monochrome-*.png`,
  `png/mark-primary-16/32/64/128/256/1024/2048.png`, `png/favicon-32.png`, `png/favicon-64.png`
  — additional sizes and background variants.
- `png/MASTER-original-generated.png` — untouched generated source (1254×1254).
- `preview/logo-system-final.png` — brand board.

Request them from the maintainer if a use case needs a size or a variant that is not committed here.

## Usage

Use the **blue mark** as the default brand asset. Use the **black mark** only when color is unavailable or when a monochrome treatment is required. Do not recolor, redraw, stretch, rotate, crop, or replace the Archimedes artwork.

## Where each asset is used

- README header (English and Chinese): `png/logo-primary.png`.
- GitHub repository avatar and social preview: `png/mark-primary-512.png` — upload through the repository **Settings** page; these slots cannot be set from the repository contents.
- Favicon: `png/favicon.ico`.
